307 Temporary Redirect

The requested resource has been temporarily moved to another URL while preserving the original HTTP request method.

What is 307 Temporary Redirect?

307 Temporary Redirect means the requested resource has temporarily moved to another location.

Unlike 302 Found, the browser must keep the same HTTP method (such as POST, PUT, DELETE, or GET) when following the redirect.

Browser Example

User submits

POST /login

↓

Server

HTTP/1.1 307 Temporary Redirect

Location: /new-login

↓

Browser automatically sends

POST /new-login

HTTP Request

POST /login HTTP/1.1
Host: example.com
Content-Type: application/json

{
    "username":"john",
    "password":"******"
}

Server Response

HTTP/1.1 307 Temporary Redirect
Location: /new-login

JavaScript (Fetch API)

fetch("/login",{

    method:"POST",

    body:JSON.stringify(data)

})

.then(response=>{

    console.log(response.status);

});

Most browsers automatically follow 307 redirects while preserving the original request method.

Node.js (Express)

app.post("/login",(req,res)=>{

    res.redirect(307,"/new-login");

});

PHP Example

header(
"Location: /new-login",
true,
307
);

exit;

Nginx Example

location /login {

    return 307 /new-login;

}

Apache (.htaccess)

Redirect 307 /login /new-login

cURL Example

curl -L \
-X POST \
https://example.com/login

Request Flow

Client
   │
   ├── POST /login
   │
Server
   │
   ├── HTTP 307
   │
Client
   │
   ├── POST /new-login
   │
Server
   │
   └── 200 OK

Common Uses

  • Temporary API migration.
  • Maintenance mode.
  • Temporary login endpoint.
  • Load balancing.
  • Traffic routing.
  • Cloud infrastructure updates.
  • Temporary service relocation.

302 vs 307

Status Request Method
302 Found Method may change.
307 Temporary Redirect Method is preserved.

Real-World Examples

Scenario Status
Temporary Login Server 307
API Gateway Redirect 307
Temporary Payment Server 307
Maintenance Routing 307

Best Practices

  • Use 307 only for temporary redirects.
  • Preserve the original HTTP method.
  • Always include a valid Location header.
  • Use 308 for permanent redirects.
  • Avoid redirect loops.
