308 Permanent Redirect

The requested resource has permanently moved to a new URL while preserving the original HTTP request method.

What is 308 Permanent Redirect?

308 Permanent Redirect indicates that the requested resource has permanently moved to a new URL.

Unlike 301 Moved Permanently, the original HTTP request method (GET, POST, PUT, DELETE, etc.) is always preserved.

Browser Example

User submits

POST /checkout

↓

Server

HTTP/1.1 308 Permanent Redirect

Location: /v2/checkout

↓

Browser automatically sends

POST /v2/checkout

HTTP Request

POST /checkout HTTP/1.1
Host: example.com
Content-Type: application/json

{
    "product": "Laptop"
}

Server Response

HTTP/1.1 308 Permanent Redirect
Location: /v2/checkout

JavaScript (Fetch API)

fetch("/checkout",{

    method:"POST",

    body:JSON.stringify(data)

})

.then(response=>{

    console.log(response.status);

});

Modern browsers automatically follow a 308 Permanent Redirect while preserving the original HTTP method.

Node.js (Express)

app.post("/checkout",(req,res)=>{

    res.redirect(308,"/v2/checkout");

});

PHP Example

header(
"Location: /v2/checkout",
true,
308
);

exit;

Apache (.htaccess)

RewriteEngine On

RewriteRule ^checkout$ /v2/checkout [R=308,L]

Nginx Example

location /checkout {

    return 308 /v2/checkout;

}

cURL Example

curl -L \
-X POST \
https://example.com/checkout

   │
   └── 200 OK

Common Uses

  • Permanent API migration.
  • Permanent payment endpoint changes.
  • Long-term service relocation.
  • API version upgrades.
  • Permanent infrastructure changes.
  • HTTP to HTTPS migration while preserving methods.
  • REST API endpoint replacement.

301 vs 308

Status HTTP Method
301 Moved Permanently Method may change in some clients.
308 Permanent Redirect Method is always preserved.

SEO Impact

  • Search engines treat it as a permanent redirect.
  • Helps preserve search rankings.
  • Transfers link equity to the new URL.
  • Useful for permanent website restructuring.
  • Recommended when POST requests must remain unchanged.

Real-World Examples

Scenario Status
API Version Upgrade 308
Permanent Checkout URL 308
Permanent Payment Gateway 308
REST API Migration 308

Best Practices

  • Use 308 only for permanent redirects.
  • Always include a valid Location header.
  • Use 301 if preserving the request method is not important.
  • Avoid redirect loops and chains.
  • Update internal links to the new URL.
