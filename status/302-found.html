302 Found

The requested resource has been temporarily moved to another URL.

Home > 3xx Redirection > 302 Found

What is 302 Found?

302 Found means the requested resource is temporarily available at another URL.

Unlike 301 Moved Permanently, the original URL should continue to be used because the redirect is only temporary.

Browser Example

User visits

https://example.com/login

↓

Server

HTTP/1.1 302 Found

Location: /dashboard

↓

Browser opens

https://example.com/dashboard

HTTP Request

GET /login HTTP/1.1
Host: example.com

Server Response

HTTP/1.1 302 Found
Location: /dashboard

JavaScript Example

window.location.href =
"/dashboard";

Node.js (Express)

app.get("/login",(req,res)=>{

    res.redirect("/dashboard");

});

PHP Example

header(
"Location: /dashboard",
true,
302
);

exit;

Apache (.htaccess)

Redirect 302 /login /dashboard

Nginx Example

location /login {

    return 302 /dashboard;

}

cURL Example

curl -I https://example.com/login

Common Uses

  • User login redirects.
  • Temporary maintenance pages.
  • A/B testing.
  • Seasonal promotions.
  • Language selection.
  • Temporary campaign pages.
  • Authentication workflows.

SEO Impact

  • Search engines treat it as temporary.
  • The original URL usually remains indexed.
  • Do not use 302 for permanent moves.
  • Use 301 when the change is permanent.

Real-World Examples

Original URL Temporary URL
/login /dashboard
/sale /summer-sale
/home /maintenance
/offer /special-offer

Best Practices

  • Use 302 only for temporary redirects.
  • Do not replace permanent redirects with 302.
  • Always provide a valid Location header.
  • Avoid unnecessary redirect loops.
  • Monitor redirect performance.
