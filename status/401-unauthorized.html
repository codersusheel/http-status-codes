What is 401 Unauthorized?

401 Unauthorized means the client must authenticate before the server will allow access to the requested resource.

It usually occurs when the authentication token, API key, session, or login credentials are missing, invalid, or expired.

Authentication Flow

Client
   │
   ├── Request Resource
   │
Server
   │
   ├── Verify Token
   │
   ├── Invalid Token
   │
   └── HTTP 401

Common Causes

  • Missing login credentials.
  • Expired JWT token.
  • Invalid API key.
  • Expired session.
  • Missing Authorization header.
  • Invalid username or password.
  • OAuth authentication failure.

How to Fix

  • Log in again.
  • Refresh expired access tokens.
  • Verify API keys.
  • Send the Authorization header correctly.
  • Check authentication middleware.
  • Confirm user credentials.
