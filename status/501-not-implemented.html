501 Not Implemented

The server does not support the functionality required to complete the request.

What is 501 Not Implemented?

501 Not Implemented means the server recognizes the request method but does not support it or has not implemented the required functionality.

This error usually occurs when a client sends an unsupported HTTP method or requests a feature that the server has not implemented.

Browser Example

Client sends

PATCH /users

↓

Server doesn't support PATCH

↓

HTTP/1.1 501 Not Implemented

API Request

PATCH /api/users/10 HTTP/1.1
Host: api.example.com

Server Response

HTTP/1.1 501 Not Implemented
Content-Type: application/json

{
    "success": false,
    "error": "Not Implemented"
}

JavaScript (Fetch API)

fetch("/api/users/10",{

    method:"PATCH"

})

.then(response=>{

    if(response.status===501){

        console.log("Feature not supported");

    }

});

Node.js (Express)

app.patch("/users/:id",(req,res)=>{

    res.status(501).json({

        error:"Not Implemented"

    });

});

PHP Example

http_response_code(501);

echo json_encode([

    "error"=>"Not Implemented"

]);

cURL Example

curl -X PATCH \
https://api.example.com/users/10

Request Flow

   │
   ├── Unsupported Feature
   │
Server
   │
   ├── Not Implemented
   │
   └── HTTP 501

Common Causes

  • Unsupported HTTP method.
  • Feature not developed.
  • Old web server software.
  • API endpoint not implemented.
  • Framework limitation.
  • Custom server restrictions.
  • Experimental feature disabled.

How to Fix

  • Use a supported HTTP method.
  • Check the API documentation.
  • Upgrade the server software.
  • Implement the missing feature.
  • Enable the required module.
  • Contact the API provider.

501 vs 405

Status Meaning
405 Method Not Allowed Method exists but isn't allowed for this resource.
501 Not Implemented Server does not support the requested method or feature.
