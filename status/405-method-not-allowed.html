405 Method Not Allowed

The request method is recognized, but it is not allowed for the requested resource.

Home > 4xx Client Errors > 405 Method Not Allowed

What is 405 Method Not Allowed?

405 Method Not Allowed means the server understands the request, but the HTTP method (GET, POST, PUT, DELETE, etc.) is not permitted for the requested resource.

For example, sending a POST request to an endpoint that only supports GET.

Browser Example

User sends

POST /profile

↓

Server only supports

GET /profile

↓

HTTP/1.1 405 Method Not Allowed

API Request

POST /api/profile HTTP/1.1
Host: api.example.com

Server Response

HTTP/1.1 405 Method Not Allowed
Allow: GET

{
    "success": false,
    "error": "Method Not Allowed"
}

JavaScript (Fetch API)

fetch("/api/profile",{

    method:"POST"

})

.then(response=>{

    console.log(response.status);

});

Node.js (Express)

app.get("/profile",(req,res)=>{

    res.send("Profile");

});

// POST is not defined,
// so POST /profile returns 405

PHP Example

if($_SERVER["REQUEST_METHOD"]!="GET"){

    http_response_code(405);

    exit("Method Not Allowed");

}

cURL Example

curl -X POST \
https://api.example.com/profile

Request Flow

Client
   │
   ├── POST /profile
   │
Server
   │
   ├── Only GET Allowed
   │
   └── HTTP 405

Common Causes

  • Using the wrong HTTP method.
  • Incorrect API documentation.
  • Route only supports GET.
  • Route only supports POST.
  • Server configuration restrictions.
  • Framework routing mismatch.
  • REST API implementation errors.

How to Fix

  • Check API documentation.
  • Use the correct HTTP method.
  • Verify server routes.
  • Check the Allow header.
  • Update routing configuration.
  • Test using Postman or cURL.

Real-World Examples

Scenario Status

404 vs 405

Status Meaning
404 Not Found Resource does not exist.
405 Method Not Allowed Resource exists, but the HTTP method is not allowed.
