410 Gone

The requested resource has been permanently removed and is no longer available.

What is 410 Gone?

410 Gone means the requested resource has been permanently removed from the server and will not be available again.

Unlike 404 Not Found, a 410 Gone response clearly tells browsers and search engines that the resource has intentionally been removed.

User visits

API Request

GET /api/products/100 HTTP/1.1
Host: api.example.com

Server Response

HTTP/1.1 410 Gone
Content-Type: application/json

{
    "success": false,
    "error": "Resource permanently removed."
}

JavaScript (Fetch API)

fetch("/api/products/100")

.then(response=>{

        console.log("Resource permanently removed");

});

Node.js (Express)

app.get("/old-post",(req,res)=>{

    res.status(410).json({

});

echo json_encode([

Server
   │

   │
   └── HTTP 410 Gone

Common Causes

  • Deleted blog posts.
  • Removed products.
  • Deprecated API endpoints.
  • Expired promotional pages.
  • Removed downloadable files.
  • Discontinued services.
  • Content removed intentionally.

How to Fix

  • Restore the resource if needed.
  • Update internal links.
  • Use a 301 redirect if content moved.
  • Remove broken links.
  • Update search engine sitemaps.
  • Create replacement content when appropriate.

SEO Impact

  • Search engines remove the URL from their index faster than a 404.
  • Useful when content is intentionally deleted.
  • Avoid using 410 if the page may return later.
  • Use 301 instead when content has a new location.
