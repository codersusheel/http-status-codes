504 Gateway Timeout

The gateway or proxy server did not receive a timely response from the upstream server.

What is 504 Gateway Timeout?

504 Gateway Timeout means a gateway or proxy server waited too long for a response from the upstream server.

This usually happens when a reverse proxy, load balancer, CDN, or API gateway cannot receive a response before the timeout period expires.

Common Causes

  • Slow backend server.
  • Database queries taking too long.
  • Reverse proxy timeout.
  • Network connectivity issues.
  • Overloaded application server.
  • Cloud service delays.
  • Firewall or routing problems.

How to Fix

  • Check backend server health.
  • Optimize slow database queries.
  • Increase proxy timeout settings.
  • Restart affected services.
  • Monitor CPU, RAM, and network usage.
  • Review application and proxy logs.

502 vs 504

Status Meaning
502 Bad Gateway Gateway received an invalid response from the upstream server.
504 Gateway Timeout Gateway received no response before the timeout expired.
