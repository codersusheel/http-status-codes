502 Bad Gateway

The server received an invalid response from an upstream server while processing the request.

What is 502 Bad Gateway?

502 Bad Gateway means a server acting as a gateway or proxy received an invalid response from another server.

This commonly occurs with reverse proxies, load balancers, CDNs, or API gateways when the backend server fails to respond correctly.

Common Causes

  • Backend server crashed.
  • Reverse proxy configuration error.
  • Invalid response from upstream server.
  • Load balancer issues.
  • DNS resolution problems.
  • Firewall blocking backend.
  • Cloudflare or CDN communication failure.

How to Fix

  • Check backend server status.
  • Restart the application.
  • Review Nginx or Apache configuration.
  • Verify proxy settings.
  • Check DNS and network connectivity.
  • Inspect server logs.
