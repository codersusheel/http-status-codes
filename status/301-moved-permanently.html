301 Moved Permanently

The requested resource has permanently moved to a new URL.

What is 301 Moved Permanently?

301 Moved Permanently indicates that the requested resource has permanently moved to a new location.

Browsers automatically redirect users to the new URL, and search engines update their indexes to use the new address.

Browser Example

User opens

https://example.com/blog

↓

Server

HTTP/1.1 301 Moved Permanently

Location: https://example.com/articles

↓

Browser automatically opens

https://example.com/articles

HTTP Request

GET /blog HTTP/1.1
Host: example.com

Server Response

HTTP/1.1 301 Moved Permanently
Location: https://example.com/articles

JavaScript Example

window.location.replace(
    "https://example.com/articles"
);

Node.js (Express)

app.get("/blog",(req,res)=>{

    res.redirect(301,"/articles");

});

PHP Example

header(
"Location: /articles",
true,
301
);

exit;

Apache (.htaccess)

Redirect 301 /blog /articles

Nginx Example

location /blog {

    return 301 /articles;

}

cURL Example

curl -I https://example.com/blog

Request Flow

Browser
   │
   ├── GET /blog
   │
Server
   │
   ├── 301 Redirect
   │
Browser
   │
   ├── Opens New URL
   │
Server
   │
   └── 200 OK

Common Uses

  • Changing page URLs.
  • Website redesign.
  • Domain migration.
  • HTTP to HTTPS redirects.
  • SEO-friendly URL updates.
  • Removing duplicate pages.
  • Moving blog articles.

SEO Benefits

  • Transfers ranking signals to the new URL.
  • Prevents duplicate content issues.
  • Preserves backlinks.
  • Improves user experience.
  • Recommended for permanent URL changes.

Real-World Examples

Old URL Redirects To
/blog /articles
http://example.com https://example.com
/old-course /new-course
/old-product /products/new

Best Practices

  • Use 301 only for permanent redirects.
  • Always redirect to the most relevant page.
  • Avoid redirect chains.
  • Update internal links after redirecting.
  • Test redirects regularly.

301 vs 302

301 Permanent Redirect
302 Temporary Redirect
