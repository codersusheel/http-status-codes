201 Created

The request was successful and a new resource has been created on the server.

What is 201 Created?

201 Created indicates that the server successfully processed the request and created a new resource.

It is most commonly returned after a successful POST request such as creating a user, blog post, product, order, or file.

API Request

POST /api/users HTTP/1.1
Host: api.example.com
Content-Type: application/json

{
    "name": "John",
    "email": "john@example.com"
}

Server Response

HTTP/1.1 201 Created
Location: /api/users/101

{
    "success": true,
    "message": "User created successfully.",
    "id": 101
}

JavaScript (Fetch API)

fetch("/api/users",{

    headers:{

    },

    body:JSON.stringify({

        email:"john@example.com"

    })

.then(response=>{

    console.log(response.status);

});

Node.js (Express)

app.post("/users",(req,res)=>{

    res.status(201).json({

});

  • Add a new product.
  • Create an order.
  • Upload a file.
  • Create a support ticket.
  • Register a new device.

Best Practices

  • Use 201 only when a new resource is created.
  • Return the created resource if possible.
  • Include the Location header.
  • Use 200 OK when updating an existing resource.
  • Validate user input before creating data.

200 vs 201

Status Use Case
200 OK Existing resource returned successfully.
201 Created New resource successfully created.

Related Status Codes

Request completed successfully.

202 Accepted
