What is 200 OK?

200 OK is the most common HTTP success status code. It means the server successfully received, understood and processed the client's request.

Whenever you open a webpage, call an API, submit a request or load data successfully, the server often responds with 200 OK.

Browser Example

User opens

https://example.com

↓

Server

HTTP/1.1 200 OK

↓

Homepage loads successfully

API Request

GET /api/users HTTP/1.1
Host: api.example.com

Server Response

HTTP/1.1 200 OK
Content-Type: application/json

{
    "success": true,
    "message": "Users loaded successfully.",
    "users": [
        {
            "id": 1,
            "name": "John"
        }
    ]
}

JavaScript (Fetch API)

fetch("/api/users")

.then(response => {

    console.log(response.status);

    return response.json();

})

.then(data => {

    console.log(data);

});

cURL Example

curl -X GET https://api.example.com/users

Common Uses

  • Opening a website.
  • Loading user profiles.
  • Fetching products from an API.
  • Successful login requests.
  • Reading blog articles.
  • Downloading files.
  • Loading dashboard data.

Developer Tips

  • Use 200 only when the request succeeds.
  • Return useful response data.
  • Use JSON for REST APIs.
  • Do not use 200 for errors.
  • Choose 201 when creating a new resource.

Related Status Codes

201 Created

A new resource was successfully created.

204 No Content

Success without returning any content.

404 Not Found

The requested resource could not be found.
