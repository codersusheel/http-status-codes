304 Not Modified

The requested resource has not changed since the last request, so the browser can use its cached copy.

What is 304 Not Modified?

304 Not Modified means the requested resource has not changed since the browser last downloaded it.

Instead of downloading the file again, the browser loads the cached version, saving bandwidth and making websites load faster.

Browser Example

User visits

https://example.com/logo.png

↓

Browser stores the image

↓

User refreshes the page

↓

Server

HTTP/1.1 304 Not Modified

↓

Browser uses cached image

HTTP Request

GET /logo.png HTTP/1.1
Host: example.com
If-None-Match: "abc123"

Server Response

HTTP/1.1 304 Not Modified
ETag: "abc123"

JavaScript (Fetch API)

fetch("/logo.png")

.then(response=>{

    console.log(response.status);

});

Modern browsers automatically handle 304 Not Modified responses using the browser cache.

Node.js (Express)

app.use(express.static("public",{

    etag:true,

    lastModified:true

}));

PHP Example

header('HTTP/1.1 304 Not Modified');
exit;

cURL Example

curl -I \
-H 'If-None-Match: "abc123"' \
https://example.com/logo.png

Request Flow

Browser
   │
   ├── Requests File
   │
Server
   │
   ├── File Unchanged
   │
   └── HTTP 304
   │
Browser
   │
   └── Uses Cached Copy

Common Uses

  • Images
  • CSS files
  • JavaScript files
  • Fonts
  • Website logos
  • API caching
  • Static website assets

Benefits

  • Faster page loading.
  • Reduces bandwidth usage.
  • Improves website performance.
  • Lowers server load.
  • Provides a better user experience.

200 vs 304

Status Meaning
200 OK Returns the complete resource.
304 Not Modified Use the cached version.
