About 3xx Status Codes

The 3xx HTTP Status Codes tell the browser or client that the requested resource is available at another location or that additional action is required before the request can be completed.

Available Status Codes

301 Moved Permanently

Resource has permanently moved to a new URL.

302 Found

Resource is temporarily available at another URL.

304 Not Modified

Cached version can be used.

307 Temporary Redirect

Temporary redirect without changing the request method.

308 Permanent Redirect

Permanent redirect while preserving the request method.

Where are 3xx Codes Used?

  • Website URL changes
  • SEO-friendly redirects
  • Domain migration
  • HTTP to HTTPS redirection
  • Browser caching
  • Temporary maintenance pages
  • Load balancing

Example

Request

GET /blog

↓

HTTP/1.1 301 Moved Permanently
Location: /articles

↓

Browser automatically opens

/articles
