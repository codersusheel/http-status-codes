About 1xx Status Codes

The 1xx HTTP Status Codes are Informational Responses. These responses mean that the request has been received and the client should continue sending the request or wait for the final response.

Available Status Codes

100 Continue

Continue sending the request body.

101 Switching Protocols

Server is switching to another protocol.

102 Processing

Server is processing the request.

Where are 1xx Codes Used?

  • Large file uploads
  • API communication
  • HTTP/2 & HTTP/3 connections
  • WebSocket connections
  • Performance optimization
