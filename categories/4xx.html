4xx Client Errors

Client Error responses indicate that there is a problem with the client's request. These errors usually occur because of an invalid request, missing permissions, incorrect URLs, or other issues on the client side.

About 4xx Status Codes

The 4xx HTTP Status Codes indicate that the server received the request, but it cannot process it because of an issue caused by the client.

These are the most common errors developers encounter while building websites, REST APIs, mobile applications, and web services.

Available Status Codes

400 Bad Request

The request is invalid or malformed.

401 Unauthorized

Authentication is required.

403 Forbidden

Access to the resource is denied.

404 Not Found

The requested resource was not found.

405 Method Not Allowed

The HTTP method is not allowed.

408 Request Timeout

The request took too long to complete.

409 Conflict

Request conflicts with the current resource state.

410 Gone

The resource has been permanently removed.

429 Too Many Requests

Too many requests have been sent in a short period.

Where are 4xx Codes Used?

  • Wrong website URLs
  • Invalid API requests
  • Login and authentication failures
  • Permission or access restrictions
  • Expired sessions
  • Broken links
  • Rate limiting APIs
  • Deleted web pages

Example

Request

GET /profile/999999

↓

HTTP/1.1 404 Not Found

    "error": "Profile not found"

Real-World Examples

  • 400 → Invalid form submission
  • 401 → Login token missing
  • 403 → Admin page without permission
  • 404 → Deleted webpage
  • 405 → Using POST instead of GET
  • 408 → Slow internet connection
  • 409 → Duplicate username
  • 410 → Removed API endpoint
  • 429 → API rate limit exceeded
