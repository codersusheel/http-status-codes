About 2xx Status Codes

The 2xx HTTP Status Codes indicate that the request was completed successfully. These are the most common responses returned by websites, APIs, applications, and web servers.

Available Status Codes

200 OK

The request completed successfully.

201 Created

A new resource was created successfully.

202 Accepted

The request has been accepted for processing.

204 No Content

Request succeeded but no content is returned.

Where are 2xx Codes Used?

  • Website pages loading successfully
  • REST API requests
  • User login and authentication
  • Database operations
  • File uploads
  • Form submissions
  • Resource creation

Example

Request

GET /api/users

↓

HTTP/1.1 200 OK

{
    "success": true,
    "users": []
}
